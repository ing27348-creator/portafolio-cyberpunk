# Portafolio Profesional Cyberpunk

Primer ejercicio de la asignatura **Inteligencia Artificial (506494)**.
Autor: **Ing. Claudio Yunior**

## Objetivo
Crear un portafolio web básico, responsivo y profesional con estética cyberpunk (verde neón sobre negro) y publicarlo en GitHub Pages.

## Tecnologías
- **HTML5**: estructura semántica (navegación, secciones, formulario).
- **CSS3**: tema verde y negro, efecto glitch, paneles con esquinas cortadas, líneas de escaneo.
- **JavaScript**: lluvia de código en canvas, texto que se escribe solo, barras y contadores animados al hacer scroll, formulario de contacto.
- **Bootstrap 5**: rejilla responsiva y barra de navegación.

## Estructura del proyecto
- `index.html`: estructura de la página.
- `style.css`: estilos (tema verde y negro).
- `script.js`: interactividad.
- `README.md`: documentación del proyecto.

## Secciones
1. Inicio: nombre con efecto glitch y gráfico SVG animado.
2. Sobre mí: descripción y estadísticas.
3. Habilidades: barras de progreso y herramientas.
4. Proyectos: tarjetas de proyectos.
5. Contacto: datos y formulario.

## Diseño responsivo
La página se adapta a celular, tableta y computadora gracias a la rejilla de Bootstrap y a unidades relativas en CSS. Respeta la preferencia de movimiento reducido del sistema.

## Publicación
1. Repositorio público en GitHub.
2. Publicado con GitHub Pages desde la rama `main`, carpeta raíz.
